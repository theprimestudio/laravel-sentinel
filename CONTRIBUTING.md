# Contributing to Laravel Sentinel

Thank you for considering contributing to Laravel Sentinel!

## Development & Testing Workflow
1. Clone the repository and install dependencies:
   ```bash
   composer install
   ```
2. Run the test suite:
   ```bash
   vendor/bin/phpunit
   ```
3. Run code formatting:
   ```bash
   vendor/bin/pint
   ```
4. Run static analysis:
   ```bash
   vendor/bin/phpstan analyse
   ```

## Security Vulnerabilities
If you discover a security vulnerability within Laravel Sentinel, please consult the `security.txt` specification or email `hello@theprimestudio.com`. All security vulnerabilities will be promptly addressed.
